# Product Brief

MyScheduler는 PC와 Android에서 함께 쓰는 개인 일정·Task 관리 PWA다. 현재 핵심 사용 시나리오는 채용 지원, 시험, 면접, 발표일처럼 일정이 여러 개 동시에 생기는 구직 활동 관리다.

## 핵심 경험
- 자연어로 여러 일정을 한 번에 적고 등록 전 해석 결과를 검토한다.
- `마감`, `시험`, `발표`, `면접`, `일반` 유형을 자동 분류하고 캘린더에서 색으로 구분한다.
- 일정 하나를 Task로 보고 완료 상태와 메모/준비물을 함께 관리한다.
- 이메일+비밀번호 로그인으로 PC↔Android에서 같은 Task를 동기화한다.
- PWA 설치와 Web Push로 백그라운드 일정 알림을 받는다.

## 자연어 입력 원칙
- 외부 LLM API 없이 규칙 기반 한국어 파서를 기본으로 사용해 운영 비용을 0원으로 유지한다.
- 날짜/시간/분류/알림/메모를 파싱하고 등록 전 미리보기에서 사용자가 수정할 수 있게 한다.
- 시간 생략 시 채용 마감은 23:59, 그 외 일정은 09:00을 기본값으로 둔다.
- 해석이 어려운 입력은 조용히 추측해서 저장하지 않고 미리보기 단계에서 확인하게 한다.

## 기본 기능
- 월간 달력 및 Task 목록 뷰
- 자연어 다건 등록과 수동 입력 fallback
- Task 메모, 완료, 삭제
- 다음 일정 헤더 표시
- Android/PC 반응형 UI
- 홈 화면 설치 가능한 PWA
- 외부 서비스가 없을 때 localStorage 저장
- Supabase Auth/Database 동기화
- Push subscription과 서버 scheduler 기반 Web Push

## 이후 확장 후보
- 반복 일정과 다중 알림
- 채용 전형 단계 묶음(지원→서류→필기→면접→최종)
- 규칙 기반 파서가 처리하지 못하는 문장에 한해서 선택적 LLM fallback
- 링크/회사/직무 필드 및 검색·필터

## 비목표
Google Calendar 완전 호환, 팀 협업, 복잡한 조직 권한 모델은 우선 구현하지 않는다.
