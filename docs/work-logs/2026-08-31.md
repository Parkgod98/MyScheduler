## 08:40 — 채용 일정 중심 UX 개편

### 작업 내용
- Magic Link 로그인을 이메일+비밀번호 로그인/회원가입으로 변경
- 외부 LLM API 없이 동작하는 한국어 일정 파서 추가
- 자연어 다건 입력 → 미리보기 → 일괄 저장 플로우 추가
- 마감/시험/발표/면접/일반 분류와 캘린더 색상 표시 추가
- 월간 캘린더와 전체 Task 뷰를 분리하고 Task 완료 상태 지원
- Task별 메모/준비물 수정 UI 추가
- 기존 Supabase `events`에 `category`, `completed` 컬럼을 추가하는 migration 작성
- 모바일에서 직접 시간 입력을 최소화하고 자연어 등록을 기본 동선으로 변경

### 주요 판단
- 채용 일정 문장은 날짜/시간/분류 키워드가 비교적 정형화돼 있어 우선 규칙 기반 파서로 운영비 0원을 유지
- 오인식 위험 때문에 파싱 결과를 즉시 저장하지 않고 반드시 미리보기 후 등록
- 시간 미입력 시 채용 마감은 23:59, 일반/시험/발표는 09:00 기본값 사용
- LLM은 향후 규칙 파서 실패 시 선택적 fallback으로만 고려

### 외부 설정
기존 Supabase 프로젝트는 `supabase/migrations/20260831_recruiting_tasks.sql`을 SQL Editor에서 한 번 실행해야 한다. 인증 메일 없이 쓰려면 Supabase Email provider의 Confirm Email을 끈다.
