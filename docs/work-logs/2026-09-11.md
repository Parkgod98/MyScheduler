# 2026-09-11 작업 로그

## Task 완료 이력 조회
- Task 화면에 `진행중 / 완료 / 전체` 상태 필터를 추가한다.
- 기존 `전체 / 마감 / 시험 / 발표 / 면접 / 일정` 카테고리 필터와 상태 필터를 조합해 조회한다.
- 각 상태/카테고리 필터에 현재 조건 기준 Task 개수를 함께 표시한다.
- 완료 처리한 Task는 삭제하지 않고 `완료`/`전체`에서 다시 조회할 수 있다.
- 완료 Task도 연필 수정과 완료 취소를 지원해 다시 진행중 상태로 복구할 수 있다.
- 기한이 지난 미완료 Task는 더 이상 Task 화면에서 사라지지 않고 진행중 목록 상단에 유지한다.
- 기한이 지난 미완료 Task에는 `기한 지남` 배지를 표시한다.
- 완료 Task에는 `완료` 배지를 표시하고 카드 시각 상태를 구분한다.

## 데이터 / 외부 설정
- 기존 `events.completed` boolean만 사용한다.
- DB schema 및 migration 변경 없음.
- 새 환경변수 없음.
- 상단 다음 일정과 7일 내 일정 요약은 기존처럼 미래 미완료 Task 기준을 유지한다.
