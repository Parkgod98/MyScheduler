# 2026-09-01 작업 로그

## 기존 일정 전체 수정 기능

### 작업 내용
- Task 카드에 `일정 수정` 진입 동선 추가
- 기존 일정의 제목, 날짜·시간, 카테고리, 알림 시간을 수정할 수 있는 편집 UI 추가
- 편집 중 메모와 준비물 체크리스트도 함께 변경하고 한 번에 저장하도록 구성
- Supabase 사용 시 기존 `events` row를 유지한 채 필요한 필드만 UPDATE
- 로컬 모드에서도 같은 편집 동작을 유지하고 수정 후 일정 시간 기준으로 재정렬
- 저장 실패 시 편집 상태를 유지하고, 빈 제목·잘못된 날짜·음수 알림 시간을 검증
- 구독 캘린더 일정은 기존과 동일하게 읽기 전용 유지

### 주요 판단
- 일정 수정으로 `event_id`를 바꾸지 않아 기존 일정의 정체성과 연결 관계를 유지한다.
- 알림 발송은 현재 event의 `starts_at`과 `reminder_minutes`를 매번 기준으로 계산하므로 수정된 일정/알림 시간이 다음 스케줄러 실행부터 반영된다.
- 별도 DB 컬럼이나 migration은 필요하지 않다.

### 변경 검증
PR에서 `validate → lint → typecheck → build`와 Android widget build를 실행한다.
