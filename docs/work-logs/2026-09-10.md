# 2026-09-10 작업 로그

## 기간 일정
- `events.ends_at` 선택 필드를 추가해 단일 일정과 기간 일정을 같은 모델로 관리한다.
- `ends_at >= starts_at` DB 제약과 기간 조회용 index를 추가한다.
- 자연어 입력에서 `9월 10일부터 9월 14일까지`, `9월 10일 ~ 9월 14일` 형태를 기간으로 해석한다.
- 빠른추가 미리보기와 기존 Task 편집 화면에서 종료 시각을 직접 설정하거나 해제할 수 있다.
- 월간 캘린더는 기간에 포함되는 모든 날짜에 일정을 노출하고, 주 단위로 이어지는 연속 색상 바로 표시한다.
- 기간 일정의 Task 정렬/D-day/Push reminder는 종료 시각 기준으로 계산한다.
- 구독 캘린더 RPC도 기간 일정이 조회 범위와 겹치면 반환하고 `ends_at`을 전달하도록 변경한다.

## 날짜 컨텍스트 빠른추가
- 날짜 Bottom Sheet의 `이 날짜에 일정 추가`에서 선택 날짜를 빠른추가 화면으로 전달한다.
- 날짜 컨텍스트가 있으면 자연어에 날짜를 다시 적지 않아도 해당 날짜로 해석한다.
- 빠른추가 화면 상단에 적용 중인 날짜를 명확히 표시하고 필요하면 컨텍스트를 해제할 수 있다.
- 하단 네비게이션의 일반 `빠른추가`는 기존처럼 날짜 컨텍스트 없이 동작한다.
